JRMSU AI-Library System – Admin Flowchart (Text + Mermaid)

This file describes the **admin-side flows** across:
- Main web app (manual login, 2FA, QR login, admin registration)
- Mirror login page (physical library entry/exit, QR borrow/return)
- Python backend (auth, sessions, library operations, notifications, system admin)
- Databases (`jrmsu_library`, optional `library_system_ai`)

You can paste the Mermaid block below into the Mermaid Live Editor to visualize it.
