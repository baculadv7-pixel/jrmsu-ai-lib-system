OPTIONAL – KILL/BREAK BUSY PORTS
--------------------------------------

If a port is already in use and you want to FREE it manually (without the Start-All-Enforced.ps1 script), you can run these from PowerShell AS NEEDED.

Example: Kill anything on port 8080
-----------------------------------
$port = 8080
$connections = Get-NetTCPConnection -LocalPort $port -State Listen -ErrorAction SilentlyContinue
if ($connections) {
  $pids = $connections | Select-Object -ExpandProperty OwningProcess -Unique
  Write-Host "Killing processes on port $port: $($pids -join ', ')"
  foreach ($pid in $pids) {
    Stop-Process -Id $pid -Force -ErrorAction SilentlyContinue
  }
} else {
  Write-Host "No process found on port $port."
}

You can change `$port = 8080` to any of:
- 8080 (main app)
- 8081 (mirror app)
- 5000 (backend)
- 5002 (AI server)
- 11434 (Ollama)
